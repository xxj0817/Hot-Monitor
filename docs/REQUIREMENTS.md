# Hot-Monitor 热点雷达 - 需求文档

> 版本 v1.0 | 2026-09 | 已评审确认（React+Vite+Tailwind / Express+SQLite / 30 分钟频率）

## 1. 背景与目标

使用者是一位 AI 编程博主，需要**第一时间**掌握 AI 大模型等热点动态，走在资讯第一线。不能依赖人工手动搜索，需要工具**自动发现**热点变化并**及时通知**。轻量工具类项目，敏捷开发。

## 2. 使用角色与场景

- 关键词哨兵：手动输入要监控的关键词（如 Claude、GPT-5、Gemini），关键词**真的出现**新动态时（AI 识别假冒/标题党/无关内容）第一时间通知。
- 热点雷达：每隔一段时间自动搜集指定范围（如"AI 编程"）内的热点供浏览。
- 技能化：把监控与发现热点的能力封装成 Agent Skills，交给其他 AI 使用。

## 3. 功能需求

### FR1 关键词哨兵（Keyword Watch）
- 添加/删除/启停关键词；按固定周期（默认每 30 分钟）扫描多信源新内容。
- AI 判定：是否强相关 + 是否可信真实（过滤标题党、营销号、假消息、旧闻炒作）。
- 判定为"真·新热点"立即触发通知（页内 Toast + 浏览器桌面通知 + 通知中心），留痕。
- 每条判定可视化（信号灯：可信 / 存疑 / 疑似假 / 无关）；支持手动触发扫描。

### FR2 领域热点雷达（Trend Radar）
- 可配置领域范围（默认"AI 编程"，中英文检索词）。
- 按固定周期从多信源采集，AI 聚合去重、提炼、评估可信度、计算热度并分级（S/A/B/C）。
- Web 页面按热度呈现热点榜（附来源链接/时间/摘要）；支持手动刷新。

### FR3 多信源采集
- 多信息源并行，避免单一信源盲区。
- 网页搜索爬虫（无 API、控频）；Twitter/X 走 twitterapi.io Advanced Search。
- 信源适配器可插拔；Key 缺失自动降级（无 Twitter Key 用演示源；无 AI Key 本地规则判定），界面提示补齐。

### FR4 通知
- 页内实时推送 + 浏览器桌面通知；通知中心留存历史、标记已读。
- 渠道适配层预留（Server酱/Telegram/Webhook 二期）。

### FR5 前端页面
- 响应式；视觉独特（情报终端风格，见设计文档）；信号灯/热力/实时流/信源健康可视化。

### FR6 Agent Skills
- 封装"采集 -> AI 判定/提炼 -> 结构化输出"核心链路为可复用技能（SKILL.md + 脚本），支持无 Key 演示。

## 4. 技术需求（已确认）

- 前端 React + Vite + Tailwind CSS；后端 Node.js + Express；存储 SQLite（better-sqlite3）。
- AI：OpenRouter（OpenAI 兼容），模型可配置；默认免费模型 nvidia/nemotron-3-super-120b-a12b:free。
- 本机常驻运行；先完成网页版并确保可用，再开发 Agent Skills。

## 5. 非功能需求

- 轻量、本地优先、容错（单信源失败不影响整体）、爬虫控频合规、中文支持、Key 仅存本地 .env。

## 6. 验收标准

1. 配置 Key 后关键词哨兵可完成真实 AI 判定并入库。
2. 热点雷达可采集多信源并生成热点榜，前端可见。
3. 页面打开时能收到"真热点"实时提醒与桌面通知。
4. 任一 Key 缺失仍可演示全流程并明确提示补齐项。
5. 移动端可用且风格独特。
6. Agent Skills 可被其他 AI 加载执行并输出结构化热点。
